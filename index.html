How it works

Connect the desk and save the heights you use

01

Find your desk

Scan for nearby BLE devices and select a compatible controller. RiseMote remembers it and can reconnect automatically.

02

Save positions

Create profiles with exact heights, arrange them in any order, and optionally assign global shortcuts.

03

Move the desk

Select a profile in the main window or press its shortcut. Movement progress is shown in the system tray, and the current command can be stopped at any time.

Main features

Use the main window or the system tray

The main window shows the current height and saved profiles. When it is minimized, the tray icon shows the connection status and a small popup shows movement progress.

↕

Precise height control

Set a target in centimeters, hold the up or down button, or choose a saved profile.

⌨

Global shortcuts

Move the desk to a saved position without opening the main window.

◉

Status in the system tray

The icon is gray while disconnected and colored when connected. Movement progress appears alongside it.

⚙

Application settings

Set the allowed height range, automatic connection, window behavior, theme, and interface language.

Stream Deck

Control the desk from an Elgato Stream Deck

RiseMote can be integrated into an Elgato Stream Deck. Save a profile with a global shortcut in RiseMote, then bind that shortcut to a Stream Deck button via a Hotkey action. Pressing the button moves the desk to the saved position without opening the main window.

Compatibility

Works with IKEA IDÅSEN desks and compatible LINAK DPG controllers

Your PC communicates directly with the desk over Bluetooth LE. Compatibility depends on the controller firmware and your computer’s BLE adapter.

If Windows asks you to pair the desk, complete the pairing in Windows Settings first.

Installation

Install RiseMote on Windows

The installer contains everything RiseMote needs to run and installs the application for the current user.

  1. Download risemote-win-Setup.exe from the GitHub Releases page.
  2. Run the installer. You do not need administrator rights or a separate .NET installation.
  3. Open RiseMote, find your desk, and save your first position.
